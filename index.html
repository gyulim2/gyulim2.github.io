시스템 취약점 진단 자동화 프로젝트

KISA 주요정보통신기반시설 가이드의 Unix 항목(U-01~67)과 Web 항목(WEB-01~26)을 Ansible로 진단·조치·롤백하고, Flask 대시보드에서 진단 결과 시각화, 조치 승인, 예외(리스크 수용) 처리, Excel·PDF 보고서 생성까지 관리하는 플랫폼입니다.

  • 용도가 다른 진단 대상 서버 6대를 설계하고 취약점 주입 스크립트로 구성 (Rocky 67개 중 45개 취약, Ubuntu 10개 취약, 예외 서버 취약 7건·소명 6건)
  • 파일·디렉터리(U-14~33)와 웹(WEB-01~26) 항목 진단·조치 스크립트 작성
  • 서비스 영향을 기준으로 자동·수동 조치를 구분하고, 자동 조치는 백업 → 변경 → 서비스 상태 확인 → 재진단을 통과해야 성공으로 판정

팀 Way Better · 4인 · 2026.09.17 ~ 09.30 · AWS 인프라·Terraform 담당

AWS 인프라 보안 모니터링 및 대응 플랫폼

취약하게 만든 쇼핑몰을 AWS에 배포하고 8개 공격 시나리오를 재현해, 보안 서비스 탐지 결과를 한 대시보드에 모으고 AI 분석·설정 진단·승인 기반 조치·재진단까지 연결한 플랫폼입니다.

  • Terraform 모듈로 VPC(퍼블릭 2·프라이빗 4 서브넷), EC2 5대, 용도별 ALB·WAF 등 AWS 인프라 전체 구축
  • GuardDuty · Inspector · Security Hub 등 보안 서비스와 로그 수집 경로 구성, GitHub Actions OIDC 배포 환경 구성
  • 구축한 인프라를 33개 항목으로 자동 진단(PASS 12 · FAIL 13 · REVIEW 3)하고, 로그 보관 기간 등 FAIL 항목을 개선 후 재진단
  • 관리자 경로 허용 IP 제한, SSH 없이 SSM으로만 서버 관리

팀 Ode · 3인 · 2026.10.29 ~ 11.11

웹 모의해킹 및 침투 프로젝트

교육과정에서 제공된 쇼핑몰 웹 서비스를 주요정보통신기반시설 Web 기준 21개 항목으로 수동 점검하고, 발견한 취약점을 연계해 서버 최고 권한까지 침투했습니다.

  • Burp Suite로 요청을 조작하며 수동 진단, 19개 항목에서 취약점 39건 도출 (모두 위험도 상)
  • 파일 다운로드 → SQL 인젝션 관리자 우회 → 웹셸 → 리버스 셸 → PwnKit(CVE-2021-4034) 권한 상승으로 일반 회원에서 root 획득
  • 항목별 재현 증적과 조치 방안을 담은 93쪽 진단 보고서와 결과 발표 자료 작성
